# Model Lab

这个目录用于从零实现并训练个人小型深度学习与 NLP 模型，重点是理解模型原理、训练流程、评估方法和推理过程。

## 目录说明

| 目录 | 用途 |
| --- | --- |
| `classification/` | 分类任务，如情感、主题和意图分类 |
| `regression/` | 连续数值预测和评分预测 |
| `sequence_labeling/` | 分词、词性标注和命名实体识别 |
| `language_modeling/` | 掩码填空、下一词预测等语言建模任务 |
| `text_matching/` | 文本相似度、句对匹配和自然语言推断 |
| `information_extraction/` | 实体、关系、事件和关键词抽取 |
| `text_generation/` | 简单对话、摘要、翻译和其他序列生成任务 |
| `representation/` | 词向量、句向量、对比学习和知识蒸馏 |
| `qa_retrieval/` | 问答、语义检索和候选排序 |
| `common/` | 可复用的数据、训练、评估和工具代码 |
| `datasets/` | 小型示例数据或数据说明；大数据集不提交到 Git |
| `configs/` | 可共享的训练与模型配置 |

## 实验结构

每个具体实验在对应任务目录下单独建立子目录。可按需使用以下结构，不要为了结构完整而创建用不到的文件：

```text
experiment_name/
├── README.md       # 目标、数据、运行方法和结果
├── dataset.py     # 数据读取与预处理
├── model.py       # 模型结构
├── train.py       # 训练入口
├── evaluate.py    # 评估入口
├── predict.py     # 推理入口
└── config.yaml    # 超参数和路径配置
```

## 约定

- 优先使用小数据集和小模型验证完整流程。
- 训练、评估和推理应使用明确的入口，保持实验可复现。
- 配置中不写入密钥或个人凭证。
- 模型权重、检查点、日志和大型数据文件不应直接提交到 Git。
- 只有当代码已被多个实验共用时，才将它移入 `common/`。
